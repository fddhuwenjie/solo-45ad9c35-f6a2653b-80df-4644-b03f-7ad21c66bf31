# 开盘带 · 走速与接续校审台

浏览器内的开盘带转录校审工具。后端仅用 Python 标准库（`wsgiref` WSGI、`wave`、
`sqlite3`），前端直接使用 Web Audio API，Canvas 联动波形、频谱与时间轴。

## 运行

```bash
python3 server.py            # http://localhost:8000  (PORT 可改)
```

打开页面后「新建项目」，载入 PCM WAV（8/16/24/32-bit PCM 或 IEEE float32）与卷盘记录
（JSON 或逐行文本，见新建对话框示例）。**原始 WAV 永远只读，不会被修改。**

## 工作流

1. 在时间轴上加校准锚点（或由卷盘记录导入），逐个/一键 FFT 分析卷首校准音。
2. 标注面别（A/B）、接带点（含两侧时码）与疑似掉速区；可拖动锚点/接带点。
3. 右侧问题栏圈出波形证据；阻断项必须附理由采纳，否则相关区间保持 **unconfirmed**。
4. 框选分段，用「原声 / 校正结果」切换试听；双击波形看该点静态频谱。
5. 每次状态更新都自动生成一条**不可变修订**；需要显式归档时点「生成修订」。
6. 导出三件套：校正 WAV、时码映射 CSV、含锚点/算法参数/接续决定的 JSON。

## 阻断规则（相关区间在附理由前不得确认）

- `ambiguous_candidates` 校准音候选不唯一（选中候选也不能消除阻断）
- `out_of_range` / `no_tone_found` / `silence` / `out_of_band`
- `anchor_order` 锚点面别/时码次序相悖
- `speed_jump` 相邻锚点走速骤变（阈值可调）
- `splice_overlap` 两处接带在同一面别占用重叠时码
- `coverage_gap` 锚点间距超过 `max_gap_s`，或疑似掉速区内无校准覆盖 —— **硬阻断**：
  理由不能采纳，只有补校准锚点才能解除

## 校正算法

Hann 窗 FFT + 抛物线谱峰细化测得校准频率，走速比 `r = 测得/标称`；相邻锚点间以
`k = sqrt(r_{i-1}·r_i)` 做分段线性单调时码映射并线性重采样。卷首/卷尾超出校准覆盖的
段落原样直通且始终不确认。修订只重渲染受牵连区间，未变前缀直接复用父修订 PCM。
